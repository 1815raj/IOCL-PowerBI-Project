# IOCL-PowerBI-Project
This project presents an interactive dashboard built using Microsoft Power BI to analyze the operational and performance data of Indian Oil Corporation Limited (IOCL). The main objective is to convert raw data into meaningful insights that help in better decision-making.
The dashboard provides a detailed analysis of key metrics such as sales performance, revenue trends, regional distribution, and product-wise insights. Data was preprocessed and cleaned using Power Query to ensure accuracy and consistency before visualization.

Tools & Technologies
Microsoft Power BI
Excel / CSV Dataset
Jupyter (Data Cleaning & Transformation)
